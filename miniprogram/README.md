# 微信小程序轻量版

直接用微信开发者工具导入本目录。

## 已有能力

- 创建房间 / 六位邀请码加入
- 微信分享卡片带房间码
- 同一房间实时在线人物
- 像素房间预览
- 方向按钮移动
- 聊天
- 庆祝状态
- 点击录音 / 再点停止
- 录音上传到 V9 后端
- 播放收到的语音

## 上线前修改

`project.config.json`：

```json
"appid": "你的 AppID"
```

`app.js`：

```js
serverUrl: 'https://你的后端域名'
```

生产环境必须使用 HTTPS / WSS，并在微信公众平台配置 request/socket 合法域名。
