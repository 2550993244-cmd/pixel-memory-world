# 微信小程序入口（当前轻量版）

这个目录不是网页的完整复制版，而是“小小世界”的微信入口验证版本。

它目前可以：
- 创建房间或输入 6 位邀请码加入；
- 通过微信分享卡片带上房间码；
- 在同一个实时房间里看到其他玩家；
- 移动、聊天、庆祝；
- 录一段短语音并上传；
- 播放房间里最近收到的语音。

它和网页共用 `server/` 后端，所以邀请码和实时房间不是两套系统。

## 第一次打开前要改什么

1. 用微信开发者工具导入本目录。
2. 当前开发分支已经配置正式 AppID；不要把 AppSecret 写入仓库或发到聊天中。
3. 在 `app.js` 中把：

```js
serverUrl: 'http://localhost:8787'
```

换成你的公网 HTTPS 服务地址，例如：

```js
serverUrl: 'https://memory.example.com'
```

4. 在微信公众平台配置对应的 request 合法域名与 socket 合法域名。
5. 生产环境必须使用 HTTPS / WSS。

## 当前定位

网页端是完整体验：房间、DIY 小人、共享纪念物、音乐、回忆寻宝地图等都优先在网页端迭代。

小程序当前更像“邀请入口 + 轻互动客户端”。后续如果继续做正式小程序，建议再把 Memory Quest 用 Canvas 或游戏框架单独迁移，而不是把 DOM 页面机械复制过去。
