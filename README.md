# 小小世界 · Pixel Memory V7

V7 是一次界面和交互架构重构，重点不是继续加功能，而是让整个原型更像一个可展示、可试玩的完整产品。

## V7 重点变化

- 全面移除暗沉紫色，换成暖奶油 / 珊瑚粉 / 雾蓝 / 鼠尾草绿 / 黄油色。
- Landing 压缩空白，改成“主文案 + 活房间预览 + 3 个高密度功能入口”。
- 大厅取消固定右侧大面板，改成“完整中心场景 + 底部交互 Dock + 按需侧边抽屉”。
- 地图物件不再常驻文字标签，只有人物靠近时才浮出 `E` 互动提示。
- 按钮统一为真实下压：位移、阴影压缩、像素粒子、浏览器合成的轻触感音。
- 人物之间有轻碰撞和挤动反馈，不再直接穿过。
- 抱抱必须靠近另一个人物后才能触发。
- 所有人都能在当前站立位置放纪念物；支持礼物、信、花、票根、照片相框。
- 纪念物靠近才发光，按 E“拾起”后才展开意义。
- 房主可上传自定义背景照片。
- 背景音乐支持 3 个浏览器合成预设 + 用户上传自己的音频。
- “庆祝”是集体状态：所有当前在线的人都按下后，触发全屏纪念动画与纪念卡入口。
- 留言、纪念物、合影继续按房间保存在浏览器本地，并通过 BroadcastChannel 在同浏览器多标签页同步。

## 本地运行

```bash
cd pixel-memory-world-v7
python -m http.server 8000
```

浏览器打开：

```text
http://localhost:8000
```

## 测试多人

1. 标签页 A 创建房间并进入大厅。
2. 复制六位房间码。
3. 标签页 B 打开同一地址，选择“输入邀请码”。
4. 输入相同房间码并创建第二个像素小人。
5. 两个标签页可实时看到人物移动、碰撞、聊天、抱抱、纪念物、庆祝状态等。

> 当前仍是前端概念验证：多人同步使用 BroadcastChannel，因此只用于同一浏览器环境演示。正式联网版可将同步层替换为 Colyseus / Socket.IO / Supabase Realtime。
