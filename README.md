# 小小世界 · Pixel Memory World

> 把一个重要的日子，变成朋友们可以一起走进去的地方。

**小小世界**是一个多人在线的像素纪念空间。生日、纪念日、毕业、告别，或者任何值得认真留下的一天，都可以被做成一间可进入的小屋：朋友用自己的像素小人来到同一个房间，在里面走动、聊天、放下照片和纪念物、播放音乐、一起庆祝，还可以从房门走到室外，在一张更大的回忆地图里寻找彼此留下的内容。

**在线体验：** https://synex1213.github.io/pixel-memory-world/

---

## 你可以在这里做什么

### 创建一间只属于这一天的房间

创建者可以选择场合、主题、日期、邀请语与音乐，再 DIY 自己的像素小人。房间创建后，可以把参与链接发给朋友，也可以单独生成只看链接。

### 和朋友真的待在同一个空间里

进入房间后，参与者可以：

- 用 WASD / 方向键移动，手机网页也有触控移动
- 实时看到其他人的位置和人物造型
- 聊天、招手、抱抱、一起庆祝
- 留言、上传照片、摆放纪念物
- 播放房间音乐或自定义音乐
- 在房间里整理家具与纪念物的位置
- 保存属于自己的作者身份，之后换设备继续管理自己留下的内容

### 从房间走到 Outside

房门之外是一张可以探索的回忆地图。这里有道路、树林、河流、桥、湖边和可交互地点，也可以把照片、文字或录音做成回忆线索，藏在地图中让朋友去发现。

### 最后留下一个可以保存的纪念

聚会结束后，可以生成一张白色压纹纸张风格的纪念卡，把这一次房间里的参与者、留言与重要信息收在一起。

## 一次完整的使用流程

1. 打开网页，点击 **创建一个世界**
2. 设置场合、主题、名字、日期、邀请语和音乐
3. DIY 自己的像素小人并进入房间
4. 把 **参与链接** 发给朋友；如果只想让某人观看，可以发 **只看链接**
5. 大家进入同一个房间，聊天、移动、留下照片和纪念物
6. 从房门进入 Outside，一起探索回忆地图
7. 需要时由房主整理家具、纪念物和地图内容
8. 聚会结束后生成纪念卡，之后仍可重新回到这个世界

## 三种访问角色

| 角色 | 能做什么 |
| --- | --- |
| **Owner / 房主** | 创建房间、管理布局、整理共享内容、生成邀请、恢复和归档房间 |
| **Contributor / 参与者** | 进入房间、移动、聊天、留下自己的留言 / 照片 / 纪念物 / Outside 回忆，并管理自己创作的内容 |
| **Viewer / 只看访客** | 进入和探索已有世界，但不会进入正式参与者名单，也不能写入共享内容 |

新房间的 6 位房间码只是方便记忆的“门牌号”。真正的访问权限由邀请链接中的秘密凭证控制；房主和参与者也可以保存恢复密钥，用于换设备后继续使用原来的权限。

## 技术实现

项目目前保持轻量，没有强行引入大型前端框架。

### 前端

- 原生 **HTML / CSS / JavaScript**
- 分层像素人物素材与动作状态
- Tiled JSON 室外地图数据
- 摄像机跟随、碰撞和世界坐标转换
- DOM / CSS 场景渲染
- 渐进增强的动效与交互层

### 实时与服务端

- **Node.js**
- HTTP / REST
- WebSocket
- 本地 BroadcastChannel 兜底
- 房间、作者、Viewer / Contributor / Owner 权限校验
- 文件型持久化，并保留后续替换数据库 / 对象存储的 adapter

### 自动化

GitHub Actions 会运行浏览器级 smoke test，真实走过创建、进入房间、人物、家具编辑、Outside、权限、恢复等核心流程，避免视觉或交互改动把主流程破坏。

## 项目结构

```text
pixel-memory-world/
├── index.html                 # Web 入口
├── assets/
│   ├── css/                   # 页面、房间、人物、地图与系统样式
│   ├── js/                    # 应用、联网、地图、人物与交互逻辑
│   ├── characters/            # 分层像素人物素材
│   └── maps/                  # Outside / Tiled 地图数据
├── server/                    # Node 服务端、REST、WebSocket、上传与持久化
├── miniprogram/               # 微信小程序轻量入口
├── docs/                      # 设计、部署、产品决策与历史记录
├── .github/                   # GitHub Actions 与浏览器 smoke test
└── README.md
```

历史开发记录已经从主 README 中移出。第一次了解项目只需要看这份 README；需要深入某一部分时再进入 `docs/`。

## 本地运行

需要 Node.js 20+。

```bash
cd server
npm install
npm start
```

然后打开：

```text
http://localhost:8787
```

Node 服务会同时托管前端页面。若要在同一 Wi-Fi 下用手机测试，可以使用电脑的局域网 IP 访问对应端口。

---

## 公网部署

推荐把静态前端和实时服务分开：

```text
GitHub Pages
    │
    └── Web 前端

Node 服务
    ├── REST API
    ├── WebSocket
    ├── 上传
    └── 持久化数据
```

GitHub Pages 可以直接发布静态页面；完整的公网多人联机、上传和长期保存还需要部署 `server/`。

详细步骤见 [docs/DEPLOY.md](./docs/DEPLOY.md)。

## 项目方向

这个项目不是一次性的电子贺卡，而是一个**很多人共同留下、以后还能重新走进去的记忆空间**。

当前开发重点是让房间与 Outside 更自然、更像一个真正可长期使用的世界，同时保持无账号、低门槛进入和对参与者隐私的克制设计。
