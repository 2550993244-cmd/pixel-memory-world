# 小小世界 · Pixel Memory World

一个可以和朋友一起走进去的像素纪念空间。

生日、纪念日、毕业、告别，或者任何值得留下来的日子，都可以被做成一间多人在线的小屋。大家用自己的像素小人进入同一个房间，在里面走动、聊天、放照片和纪念物、播放音乐、一起庆祝，再从门外进入一张回忆寻宝地图。

**当前版本：V15.6 · secret invite rooms**

### V15.6 秘密邀请链接
- **D006 选择 A 已落地**：6 位门牌号继续作为好记的房间身份，但不再是新房间的完整进入凭证
- **高熵 invite token**：创建新房间时同时签发随机秘密邀请 token；公开 room payload 不返回 token 或 hash
- **链接即进入凭证**：分享链接形如 `?room=XXXXXX&invite=...`，朋友点开后自动验证并进入人物设置，不需要注册、密码页或房主在线批准
- **地址栏脱敏**：浏览器收到秘密链接后先把 token 保存到本机，再从可见 URL 中移除 `invite` 参数
- **全链路访问控制**：房间 GET、WebSocket、留言 / 纪念物写入、上传和 Outside 操作都校验当前 invite token；仅有 actor credential 不能绕过邀请层
- **不可枚举**：没有有效 invite token 时，受保护房间按 404 处理，不通过短门牌号确认房间是否存在
- **邀请轮换**：房主可以单独更换秘密链接；旧 token 立即失效，在线旧邀请会退出，但门牌号、房间内容、恢复密钥保持不变
- **旧房间兼容**：历史房间不会无提示突然锁死；房主首次生成 / 轮换秘密邀请链接后即升级到新访问模型
- **恢复密钥衔接**：新导出的房主恢复包会携带当前 invite token；旧恢复包仍能恢复所有权，之后可在邀请中心重新生成链接

### V15.5 归档优先的房间生命周期
- **D005 选择 A 已落地**：默认“删除”先进入归档，不直接销毁多人共同留下的纪念内容
- **30 天恢复期**：归档后普通访客收到 410，不能继续加入；房主仍可查看状态并重新开放
- **归档期间只读**：房间写操作返回 423，实时连接会被服务器主动断开，避免出现“表面归档但仍可偷偷修改”的状态
- **永久删除逃生口**：房主仍可选择立即永久删除，但必须再次输入完整 6 位门牌号确认
- **资源一起清理**：永久删除会同时清理房间 JSON，以及能关联到房间的照片、录音、自定义背景 / 音乐等上传资源
- **旧上传兼容**：除 V15.5 新登记的房间上传外，服务端还会扫描历史房间内容中的 `/uploads/` URL 来清理旧资源
- **自动到期**：服务器每小时执行一次归档到期清理，同时每次请求也会进行轻量过期检查

### V15.4 无账号恢复密钥
- **D004 选择 A 已落地**：继续保持“拿房间码直接进入”，不要求注册账号
- **房主恢复密钥**：可导出 `PMR1...` 恢复密钥 / `.pmrkey` 文件，包含房间所有权与个人作者身份
- **个人身份密钥**：参与者也可单独保存作者身份，用于换设备后继续证明自己留下的内容
- **先验真再导入**：恢复包带 SHA-256 校验摘要；导入时服务器会验证房主 token / actor credential，通过后才写入当前浏览器
- **即时恢复**：如果导入的是当前房间的房主密钥，不需要刷新页面即可恢复房主状态
- **恢复中心**：房间设置新增“换设备恢复”入口，并明确提示恢复密钥等同权限本身，不应公开分享

### V15.3 房主策展权限
- **D003 选择 A 已落地**：房主是共享纪念空间的策展人，可以整理 / 收起 / 移除参与者留下的纪念物，但不能改写他人的文字内容
- **作者私钥**：公开 `authorId` 与本机私密 actor credential 分离；服务器校验作者身份，刷新后仍能识别原作者
- **服务端权限**：陌生参与者不能移动别人的回忆；原作者可以编辑自己的内容；房主 token 可以整理空间但不能冒充作者
- **安全同步**：Memory / Quest 的持久化操作统一通过鉴权 REST；普通 WebSocket 不再能直接覆盖云端记忆数据
- **可恢复策展**：房主移动 / 隐藏 / 删除纪念物和门外回忆时会保留历史版本，可跨刷新恢复
- **WORLD EDITOR**：房主现在可以直接拖动参与者留下的房间纪念物；选中后可以进入管理详情

## V14 参考与取舍

这次不是把开源特效库全部塞进页面，而是按当前技术栈和项目气质做筛选：

- **Lenis**：实际接入，用于内容页的平滑滚动。
- **GSAP + ScrollTrigger**：实际接入，用于首屏与滚动编排。
- **React Bits**：项目本身是原生 HTML / CSS / JS，没有为了动效强行迁移 React；Magnet、SpotlightCard、PixelTransition 的交互逻辑被重写成原生实现。
- **Vanta**：研究了它用 WebGL / Three.js 做可交互背景的做法，但当前页面不直接加载 Vanta。原因是这个项目的核心视觉是“暖色记忆 + 像素世界”，原生低分辨率 Canvas 更轻，也更容易做成像素化的环境光。
- **awesome-design-md**：采用它的 DESIGN.md 工作方式，把视觉规则固化在仓库根目录，避免以后每一版都重新争论字号、圆角、阴影和交互方式。

## 第一次玩

### 创建世界

1. 打开网页
2. 点击 **创建一个世界**
3. 选择生日 / 纪念日 / 毕业 / 告别
4. 填写名字、日期和邀请语
5. 选择房间和音乐
6. DIY 自己的像素小人
7. 进入房间后复制 6 位邀请码
8. 把邀请码或链接发给朋友

### 加入世界

1. 打开网页
2. 点击 **输入邀请码**
3. 输入 6 位门牌号
4. 创建自己的像素小人
5. 推门进入房间

## 本地运行

需要 Node.js 20+。

~~~bash
cd server
npm install
npm start
~~~

然后打开：

~~~text
http://localhost:8787
~~~

服务器会同时托管前端。

同一 Wi-Fi 下，可以用电脑局域网 IP 在手机访问，例如：

~~~text
http://192.168.1.20:8787
~~~
