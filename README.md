# 小小世界 · Pixel Memory World

一个可以和朋友一起走进去的像素纪念空间。

生日、纪念日、毕业、告别，或者任何值得留下来的日子，都可以被做成一间多人在线的小屋。大家用自己的像素小人进入同一个房间，在里面走动、聊天、放照片和纪念物、播放音乐、一起庆祝，再从门外进入一张回忆寻宝地图。

**当前版本：V13.1 · interaction & cleanup**

- WASD / 方向键移动
- 手机网页触控方向键
- 家具靠近互动
- 实时聊天、抱抱、庆祝
- 留言、照片、纪念物
- 自定义房间背景
- 房间音乐与自定义音乐同步
- 多人位置实时同步
- 人物碰撞音改成更轻、更可爱的双音 boop
- 全员按下“庆祝”后进入黑屏庆生仪式：显示主角名字，并落下线幕式礼花

### Memory Quest
- 从房间里的门走到室外
- 多人一起探索
- 照片生成像素线索
- 把线索藏到地图中
- 给宝藏写文字或录音
- 其他人走过去发现并播放
- 树林、弯曲道路、分层河流、木桥、前景遮挡和环境动态
- 河岸 / 水体 / 高光分层，水面高光使用断续动态线
- 渐变天空、远近山体、虚线等高线和前后景空间层级
- 湖边可以靠近浮漂按 E 钓鱼：水下有会游动的原创像素鱼、气泡接近浮漂、咬钩水花，以及“按住收线让捕捉区追着鱼”的小游戏；钓到后像素鱼会跳出水面再放流
- 修复 V12.4 中 Outside 因历史存储声明被注释而无法进入的问题
- 木桥改为弧形 SVG 桥面，不再是一条平直矩形
- 删除地图里两个重复的“回忆路”路牌，让小路和地形自己承担引导

## 第一次玩

### 创建世界

1. 打开网页
2. 点击 **创建一个世界**
3. 选择生日 / 纪念日 / 毕业 / 告别
4. 填写名字、日期和邀请语
5. 选择房间和音乐
6. DIY 自己的像素小人
7. 进入房间后复制 6 位邀请码
8. 把邀请码或链接发给朋友

### 加入世界

1. 打开网页
2. 点击 **输入邀请码**
3. 输入 6 位门牌号
4. 创建自己的像素小人
5. 推门进入房间

## 本地运行

需要 Node.js 20+。

~~~bash
cd server
npm install
npm start
~~~

然后打开：

~~~text
http://localhost:8787
~~~

服务器会同时托管前端。

同一 Wi-Fi 下，可以用电脑局域网 IP 在手机访问，例如：

~~~text
http://192.168.1.20:8787
~~~

## 当前技术状态

前端目前仍以原生 HTML / CSS / JavaScript 为主，没有强行切换框架。

实时层：

~~~text
HTTP / REST
+
WebSocket
+
BroadcastChannel 本地兜底
~~~

地图层正在分阶段升级：

~~~text
DOM / CSS 场景
      ↓
网格化 scene-map 数据   ← 当前
      ↓
Tilemap 分层
      ↓
Tiled 编辑器
      ↓
摄像机 / 碰撞 / 更大地图
~~~
